## 本地运行

无需安装前端依赖。在仓库目录运行：

```sh
python3 -m http.server 8765
```

打开 http://localhost:8765/ 。需要通过 HTTP 访问，以载入 Three.js ES modules。

## 部署

本仓库为可直接部署的静态站点。GitHub Pages 发布源使用 `main` 分支的根目录，更新提交后自动发布。

## 实现
